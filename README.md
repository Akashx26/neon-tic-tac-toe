
# 🎮 Neon Tic-Tac-Toe

A modern, neon-themed Tic-Tac-Toe web application built using Python, Flask, HTML, CSS, and JavaScript.

Play against the computer or challenge another player in a two-player mode, all within a dark neon-inspired interface.

## ✨ Features

- **Two Game Modes**
  - Player vs Computer
  - Player vs Player

- **Three Difficulty Levels**
  - Easy
  - Medium
  - Hard

- **Custom Player Symbol**
  - Choose X or O when playing against the computer.

- **Score Tracking**
  - Separate scoreboards for each game mode.

- **Alternate First Turn**
  - The starting player changes after every match.

- **Interactive Interface**
  - Neon-themed design.
  - Smooth animations.
  - Winning-line indicator.
  - Responsive game board.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Akashx26/neon-tic-tac-toe.git
```

### 2. Navigate into the project

```bash
cd neon-tic-tac-toe
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Start the application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
